# AI Agent — ИИ-агент для управления телефоном

Android-приложение, внутри которого живёт автономный ИИ-агент на базе Claude.
Агент может управлять телефоном через инструменты: выполнять команды в shell
(в том числе с root-правами через `su`), читать/создавать/удалять файлы где
угодно, узнавать информацию об устройстве и сохранять долговременную память —
и всё это в привычном интерфейсе чата.

## Что умеет

- **Чаты** — несколько диалогов, история хранится локально (Room/SQLite).
- **Память** — агент сам решает, что запомнить (`save_memory`), и подтягивает
  сохранённые факты в системный промпт каждого нового диалога.
- **Управление телефоном** через инструменты, которые выполняются прямо на
  устройстве:
  - `run_shell` — любая команда в shell, опционально как root (`su`);
  - `read_file`, `write_file`, `list_dir`, `make_dir`, `delete_path` — работа
    с файлами в любом месте файловой системы;
  - `save_memory`, `search_memory` — долговременная память;
  - `device_info` — модель, версия Android, место, наличие root.
- **Агентный цикл** — модель сама вызывает нужные инструменты по очереди,
  получает результаты и продолжает, пока задача не будет выполнена (до 30 шагов).

## Архитектура

```
ui/            Jetpack Compose: чат, настройки, шторка со списком чатов
ui/AgentViewModel.kt   состояние, подтверждение действий
agent/AgentEngine.kt   цикл tool-use: запрос → инструменты → результаты → ...
agent/Tools.kt         описания инструментов + их выполнение на устройстве
agent/RootShell.kt     запуск команд через sh / su
network/AnthropicClient.kt   вызовы Claude Messages API через OkHttp
data/          Room: чаты, сообщения, память; настройки
```

Модель по умолчанию — `claude-opus-4-8` (меняется в настройках). Запросы идут
напрямую в `https://api.anthropic.com/v1/messages` через OkHttp: официальный
Java SDK ориентирован на JVM и официально не поддерживается на Android.

## Сборка

1. Открыть проект в **Android Studio** (Giraffe/Koala или новее — AGP 8.5,
   Gradle 8.9, Kotlin 2.0.21). Studio сама докачает Gradle по wrapper'у.
2. Дождаться синхронизации Gradle и собрать модуль `app`.
3. Установить APK на телефон (для полного доступа желателен root).

Минимальная версия Android — 8.0 (API 26).

## Первый запуск

1. Открыть **Settings** (шестерёнка) и вставить свой ключ Claude API
   (`console.anthropic.com`). Ключ хранится только на устройстве.
2. По кнопке **Grant full file access** в шторке выдать доступ ко всем файлам
   (Android 11+).
3. Если на телефоне есть root — менеджер root-доступа (Magisk и т.п.) спросит
   разрешение при первой команде с `su`.

## Безопасность

Это мощный инструмент для **вашего собственного** телефона. Несколько мер
предосторожности встроено:

- **Подтверждение действий.** По умолчанию каждое изменяющее действие (запись и
  удаление файлов, shell-команды) требует подтверждения в диалоге. Отключается
  переключателем «Auto-approve actions» — на свой страх и риск.
- **Root можно выключить** переключателем «Allow root».
- Ключ API и память не покидают устройство, кроме запросов к Anthropic.

Агент выполняет реальные команды на устройстве. Команды вроде удаления системных
файлов необратимы — внимательно читайте, что агент собирается сделать, прежде чем
нажимать «Allow».
